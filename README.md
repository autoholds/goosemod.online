# GooseMod-style recreation

A standalone fan recreation inspired by the archived GooseMod website:
- minimal dark visual language
- large hero
- feature cards
- product preview/mock UI
- animated stats
- scroll reveal animations
- responsive mobile layout

This is an independent recreation and is not affiliated with GooseMod.

Open `index.html` directly in a browser, or use VS Code Live Server.


## Icons
The recreation uses local SVG icons with a minimal outline style. The archived GooseMod repository confirms a `static` asset directory, but the binary originals could not be retrieved through the available archive interface; these SVGs are therefore an independent visual recreation, not claimed originals.
